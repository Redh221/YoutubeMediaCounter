# YouTube Media Counter

Расширение Chrome (Manifest V3), которое считает время просмотра YouTube и даёт управлять плеером с любой вкладки.

## Что умеет

- **Время просмотра.** Считается реальное время, пока играет видео в основном плеере YouTube (обычный ролик, мини-плеер или Shorts). Пауза, перемотка, реклама и превью при наведении не засчитываются. Видео на ускорении засчитывается по реальному времени: час ролика на 2× — это 30 минут.
- **Значок расширения** на вкладках YouTube показывает время за сегодня или за 7 дней. Формат (`1.4h`, `1h23`, `83m`) и цвет выбираются в настройках.
- **Топ каналов за неделю** в popup.
- **Карточка плеера** в popup: пауза, перемотка, громкость, следующее видео и скорость для YouTube-вкладки, даже когда вы на другой вкладке.
- **Мини-плеер поверх всех окон** (Document Picture-in-Picture). Открывается кнопкой 📌 в панели плеера YouTube.
- **Синхронизация между устройствами** через Google-аккаунт в Chrome. Её можно выключить на отдельном устройстве.
- **8 языков интерфейса.** По умолчанию язык браузера, переключается в настройках.

## Запуск локально

1. Откройте `chrome://extensions`.
2. Включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение» и выберите эту папку.
4. Откройте YouTube и нажмите иконку расширения.

## Структура

- `manifest.json` — конфигурация Manifest V3.
- `background/` — service worker: подсчёт времени, значок, синхронизация (`cloud-sync.js`).
- `content/` — код на страницах YouTube: `media-counter.js` считает время и управляет плеером, `player-bridge.js` работает в контексте страницы и обращается к API плеера YouTube.
- `popup/` — окно расширения.
- `options/` — страница настроек.
- `pip/` — мини-плеер поверх всех окон.
- `shared/` — общий код: карточка плеера, настройки, тема, переводы (`i18n.js`, `locales/`).
- `_locales/` — описание расширения для `chrome://extensions` на разных языках.
- `icons/` — иконки расширения.
