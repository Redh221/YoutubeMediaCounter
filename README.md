# YouTube Media Counter

Каркас расширения Chrome на Manifest V3. Popup показывает число реально проигрываемых видео на активной вкладке YouTube и общее время просмотра.

Время добавляется только пока видео воспроизводится. Пауза и перемотка не засчитываются; счётчик сохраняется между перезапусками браузера. Пока popup открыт, показатели обновляются раз в секунду.

Время также видно на значке расширения: `45s` — секунды, `12m` — минуты, `2h` — часы.

## Запуск локально

1. Откройте `chrome://extensions`.
2. Включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение» и выберите эту папку.
4. Откройте YouTube и нажмите иконку расширения.

## Структура

- `manifest.json` — конфигурация Manifest V3.
- `popup/` — интерфейс расширения.
- `content/` — код, работающий на страницах YouTube.
- `background/` — service worker для фоновой логики.
